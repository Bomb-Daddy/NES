# EXEC0195 - Classic active-country VIEW and Pass source-ledger repair

Built on complete EXEC0194. The existing Classic ASSIGN changes five worker occupation pools after a private original NES first-Spring checkpoint is imported. The game now renders a verified **before vs. after** player-country allocation under VIEW and reads the **same Classic three-order budget** when the player confirms PASS from the country screen. Previously the country screen displayed only original worker values and could debit the unrelated immutable stock checkpoint budget, leaving the derived allocation inconsistent. Gk195 view fails closed on tampered records or forged action history. It never changes source NES arrays, never guesses first-Spring RNG or opens extra commands. Other countries still show untouched source-only data. Both Classic and Enhanced APIs remain profile-separated. Nothing here demonstrates original stock NES parity or a full campaign.

Reproduce: cmake -S execution_195 -B build195 -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build195 -j6 && ctest --test-dir build195 --output-on-failure -j6. For three authentic positive checks supply PRIVATE first-Spring source files to test_gk195_classic_view as CSV fresh.json archived1175.mss world1206.mss.
