Previous tested executable inherited: EXEC0075 v0.75.0-dev1; same 1280x720 C11 Linux X11/Windows Win32-XInput source; no original fields, gameplay/profile, save paths removed. EXEC0076 was a *research* handoff and did not itself produce a newer native app. This EXEC0077 derives all actual stock reference record identities from that latest handoff. ## What actually changed
- `gk77_stock_spring.c/h` decodes all 25 original numeric fields (incl. 10 goods starting **0x22**, Food **0x36**, Gold **0x40**) from each **83-byte** country record. The exact profiles are original Mesen fresh **nesWorkRam** Mongol Spring1175 14 records, archived **nesSaveRam** Mongol Spring1175 14 records and archived **nesSaveRam** World Spring1206 27 records. SHA256 and full length are required; wrong bank/record/Profile/refused byte-for-byte. Corresponding Rate/season/order metadata came from verified original Mesen evidence and differs across source sessions (fresh 121 vs archived101). No magic 430/439 initialization. PRIVATE original ROM/records are **not in this source archive or GitHub**.
- Same **existing** native controller app: enter manual rules, press A to reach Spring viewer, **VIEW toggles actual authenticated original NES first-Spring** record to existing previews, DPAD visits all 14 or 27 countries, START returns to original source-only PRE_SETUP food/tax/payroll what-if, B returns. Wrong/private input leaves VIEW unavailable. Source campaign templates/market/battle/3 save slots do not mutate.
- Installed native CLI `--stock-spring-audit fresh|mongol|world <private-records-file>` displays all fields vs the existing original 41-country CSV. `--stock-spring-pad-check profile file` validates actual controller traversal; shipped default `test_gk77_stock_spring` checks original offsets and failure atomicity without any private data. Actual private parity run instructions and hash receipts go in QA. `GK1_STOCK_SPRING_PROFILE` + `GK1_STOCK_SPRING_RECORDS` attach optional authorized source records to GUI.

**NOT CLAIMED:** first Spring generated by port, stock RNG/initialization formula, actual strategic first turn, playable Trade, battle terminal victory, fully playable campaigns, original licensed graphics/audio, native Windows run/installer, physical Xbox test. Source-static ROM metadata and captured original runtime are different classifications; this is a tested-port read-only evidence viewer. No installed-game world auto-advance or import into gameplay. The latest original NES actual fresh reset reaches Spring; the port does not.
