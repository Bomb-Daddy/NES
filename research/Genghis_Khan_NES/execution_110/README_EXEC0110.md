# EXEC0110 — all-country source-authentic partial Spring finance staging

This is the inherited full 1280×720 native C11 research game (not a prototype replacement). New `gk110_spring_stage.c/h` and controller-visible Spring Archive START projection apply only the previously source-traced original 6502 food, tax, payroll subroutine to all 14 Mongol or all 27 World **verified pre-setup templates** atomically. The input must exactly equal a fresh load of the authenticated 41-country CSV, including all metadata and non-selected countries. Altered/reassigned workers fail instead of silently reinterpreting edited world state as original NES. `gk1_app_source_spring_stage` is linked into the same mutable application but never mutates a world or changes game phase. Projected values are **not first Spring** because original setup, population growth, age, sickness, event rolls, Rate RNG and order scheduling are not yet implemented. Three `setup_resolved`, `first_spring_ready`, `orders_granted` flags deliberately remain zero. The controller uses the existing START what-if mode in Spring Archive; the stage is now available for either scenario and 14/27-country scrolling. Unsupported or missing official CSV is rejected.

Compile and test with `cmake -S execution_110 -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j4 && ctest --test-dir build --output-on-failure`. No original ROM, checkpoint, RAM or licensed art/sound is shipped. This increment adds no native Windows execution or physical Xbox acceptance. Existing authenticated original NES fresh/archived captures remain distinct independent references and were not newly executed. Do not claim `gk110_prepare_source_finance` is a first playable Spring or a normal player action.
