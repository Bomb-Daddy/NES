# EXEC0143 — Hypothesis-gated bank-aware 6502 CFG on the complete inherited Genghis game

Inherits the exact `execution_142` C11 game and all its original controller, Classic/Enhanced, saved-checkpoint, and 14/27-country research code. This is a read-only **candidate** analysis for the authenticated original-stock 262160-byte NES ROM. `gk143_scan_authenticated` SHA256-attests the private ROM, then explores source instructions under one **explicit, externally chosen** lower PRG bank (0..14) plus the fixed bank15. A low reset vector that EXEC0142 could not follow can now be explored conditional on the selected bank. No automatic bank inference or imaginary runtime evidence.

A register write to a plausible MMC1 mapper address blocks the path, so this program does NOT pretend to know which bank appears afterward; indirect writes and runtime PC paths remain unknown. Conditional branches explore both ways. The scanner follows documented 6502 opcodes only and skips inline EF85 selector bytes. It is a static overapproximation for a single bank mapping, not proof of runtime execution, coverage, or correct first Spring. Synthetic fixture tests include decoy-bank calls, mapper barriers, invalid ROM/hypothesis refusals, and immutable app state.

Reproduce from a complete historical source ZIP extraction: `cmake -S execution_143 -B build143 -DCMAKE_BUILD_TYPE=Release && cmake --build build143 -j6 && ctest --test-dir build143 --output-on-failure -j6`. Private ROM diagnostic: `build143/test_gk143_bank_cfg --private-stock /private/original_stock.nes`; it reports aggregate counts for all fifteen low-bank hypotheses, never original bytes. Never publish original ROM, states, sprites or licensed assets. First player-ready Spring and three original orders are still blocked; game stage not advanced. Windows / NSIS / physical Xbox: NOT RUN.
