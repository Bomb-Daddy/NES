# EXEC0227 — Source-verified Enhanced practice title inventory (2026-11-12)

This is an **incremental change in the existing C11 Linux X11 / Windows Win32-XInput application** inherited verbatim from EXEC0226, not a separate simulator. It exposes the existing 80-byte Enhanced practice receipt as read-only verified title metadata: campaign (Mongol/World), country, 0–3 committed practice orders and remaining budget. Only the Enhanced profile displays this slot; the Classic stock preview remains separate. No original ROM bytes or original NES first-Spring result are embedded in this UI or public source.

The `gk227_preview_practice_slot` API checks the canonical 41-country CSV SHA, both 14/27 full pre-setup source sets, file type (symlink/reparse/directory refused), exact receipt length, receipt SHA and full source-relative replay through the inherited `gk224_load` decoder. It returns status codes for empty, inaccessible, source-refused or corrupted slots and changes its output structure only on a validated success. No `Gk1App` gameplay state is touched. It caches title metadata per selected slot/profile; only slot change, save/load, source attach or profile change invalidates the cache. Original source data remains PRE_SETUP; the 3-order demonstration remains PORT PRACTICE, never certified authentic. The four-process EXEC0226 X11 resume route now requires a correct actual title preview before controller Y.

Reproduce: `cmake -S execution_199 -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build -j8 && ctest --test-dir build -j8 --output-on-failure`. Targeted source test: `ctest --test-dir build -R GK1_227_ --output-on-failure`; actual separate-process X11 UI path: `ctest --test-dir build -R GK1_226_FourSeparateX11 --output-on-failure`. The tests cover both campaign sizes, future save progression, valid/empty/corrupt/short/symlink and altered full-source negative controls, and output non-mutation. A passing GUI smoke is not a physical Xbox test.

**Not complete:** independently generated stock first Spring, original setup/ruler/difficulty/RNG sequence, authentic three strategic orders, merchant scheduling, autonomous AI, war aftermath, diplomacy/dynasty, authentic graphics/APU, full campaign cold saves, Win32/NSIS execution, physical Xbox, two completed campaigns. No Mesen run this execution; historic fresh WorkRAM vs archived SaveRAM observations remain distinct.
