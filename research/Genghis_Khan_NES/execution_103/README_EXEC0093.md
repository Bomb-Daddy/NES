# EXEC0093 — Source-bound original NES setup 6502 opcode coverage (research build)

## Scope and chain of custody

This is the inherited COMPLETE `execution_092` game source plus the changes in
`execution_093`. The licensed KOEI ROM, saves, screen captures and raw source RAM
are owner-private and NEVER distributed in this source, installer or public QA.
The original USA stock NES ROM is required only as a private runtime input.

## New executable implementation

The shared 6502 reset interpreter now executes the ROM-observed 2A03/NMOS
instructions SEC, SBC immediate, ADC immediate/zero-page/absolute/(zero-page),Y,
STA (zero-page),Y, INC zero-page, JMP indirect with the NMOS high-byte
page-wrap, BCC/BCS, CMP (zero-page),Y, SBC (zero-page),Y, ASL A, ROL zero-page,
STX zero-page, PHP, PLP, TSX and LDY absolute. This is not a new game or an
emulator replacement. Arithmetic ignores decimal mode as required by the NES
CPU. Source reads still fail closed if unknown, and normal reset tracing still
stops at unmodeled PPUSTATUS `$2002` after 142 instructions.

## Test classification

- `VERIFIED_STATIC`: exact ROM-source counterfactual 0x80 PPUSTATUS replay
  proceeds beyond the previous opcode gate at `$EF93` into further stock
  initialization code. The 0x80 sequence is **not observed PPU timing or actual
  startup**; its purpose is to exercise genuine cartridge CPU instructions.
- `OBSERVED_RUNTIME_STOCK`: previously archived original Mesen fresh and
  restored country records; not rerun or regenerated by this change.
- `TESTED_PORT_LINUX`: CTest release, game-process/X11 and packaging evidence
  in the EXEC0093 QA receipt. Private ROM focused test only when provided.
- `NOT RUN`: native Win32 executable, Windows installer, physical Xbox and
  full original stock first Spring RNG/season/campaign parity.

## Reproduction

```
cmake -S execution_093 -B build93 -DCMAKE_BUILD_TYPE=Release
cmake --build build93 -j8
ctest --test-dir build93 -j8 --output-on-failure
GK1_ORIGINAL_STOCK_ROM=/private/owner-original-USA.nes ./build93/test_gk93_source_setup_opcode
cmake --build build93 --target package
```

The first source-derived unknown startup PPUSTATUS value remains unmodeled. The
existing 14/27 source-bound country profiles and View/Pass-only controller
continue flow are preserved. Authentic player setup/RNG, 12 locked orders,
merchant scheduler, AI, battle aftermath, diplomacy/dynasty, 1174/1205 full
campaigns, Windows and real Xbox remain open, not claimed finished.

The source implementation explicitly adds 20 instruction opcode variants
(SEC, SBC immediate, ADC immediate/zero-page/absolute/indirect-Y, STA indirect-Y,
INC zero-page, JMP indirect, BCS, BCC, CMP indirect-Y, SBC indirect-Y,
ASL accumulator, ROL zero-page, STX zero-page, PHP, PLP, TSX, LDY absolute).
These are stock-ROM source behaviors, not evidence of complete gameplay parity.
