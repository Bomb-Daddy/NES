# EXEC0055: Six-ability / five-character manual point input draft

Extends EXEC0054 existing native C11 application, no standalone competing project. Primary English NES printed manual page 8 lists SIX abilities: Leadership, Judgment, Planning, Charm, Body and Battle. Printed page 9 specifies lord + four princes, A +1 and B +10, with 100 extra points. This editor tracks a conservative **100-point aggregate draft** across 5x6 positions per campaign. Whether source ROM supplies per-character budgets and how starting stats are created is NOT established; consequently the numbers are **not applied to base abilities or actual Spring**. This is a real state-changing controller UI and save/load (2734-byte pre-setup file) but remains a research prototype. Classic and Enhanced profiles separate.

While World/Mongol candidate setup wizard is at manual statistics / awaiting-source stage: press START to edit, left/right choose lord/prince, up/down choose six abilities, A adds 1 and B adds 10; START exits. X saves and Y loads draft. Older 2594/2618/2654 files remain readable, with empty bonus drafts. No new private ROM or copyrighted artwork is included. Tests never substitute for original NES trace, native Windows or physical Xbox acceptance.
