# EXEC0057 — controller-accessible, state-changing PRE_SETUP workforce planner

Extends the **existing** Genghis Khan I standalone native C11 application from EXEC0055 and preserves the verified EXEC0056 X/Y manual-bonus correction semantics. All country records come from the exact original 41-country, 45-column economic CSV v1.07. This is an additive implementation; no original binaries, ROMs or campaign saves are modified.

On the 14-country/27-country roster screen, press Xbox **View/Back** to open the labor planner. D-pad left/right selects the source pool, up/down selects the destination pool, A transfers **one** currently drafted worker, B exits the planner, X saves the whole pre-setup state and Y cold-loads it. The five pools are Troops, Town, Masons, Artisans and Food Workers. Transfers conserve draft total/population and reject empty sources and self-transfers without numeric mutation. Both campaigns remain isolated. XInput Back and Linux joystick button 6 are mapped through the existing controller-only router; native hardware was not tested.

This is an **optional port PRE_SETUP editor**, **not** a claimed faithful original NES Assign→Labor order, command cost, AI operation or first playable Spring initialization. It changes persistent mutable scenario data in the current native application. Campaign data stays explicitly PRE_SETUP_TEMPLATE until historical initialization is proven. Classic and Enhanced research profiles remain separate.

Test: `cmake -S execution_057 -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build -j4 && ctest --test-dir build --output-on-failure`. The built application supports `--labor-plan-export FILE SCENARIO_ID COUNTRY_ID QUANTITY`, `--labor-plan-import FILE SCENARIO_ID COUNTRY_ID`, and retained `--bonus-correction-export FILE`, `--bonus-correction-import FILE`. The 2734-byte setup save is source-identity-gated, CRC checked, exclusive-create and compatible with preceding states. The CLI drives the same application input and serialization; no NES emulator or physical controller is implied. A graphics smoke option `--smoke-labor 90` draws the real 1280x720 Linux X11 window under Xvfb.
