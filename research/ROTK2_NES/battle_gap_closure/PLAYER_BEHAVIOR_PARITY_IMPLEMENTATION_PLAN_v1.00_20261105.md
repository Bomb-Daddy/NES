## What counts as equivalent player behavior
From equivalent normalized officers, ownership, province data, supplied terrain, armies, supplies and injected logical random decisions, Classic and default Enhanced must permit the same battle orders, movement, positioning, action order, damage, results, fortunes, prisoners, troop scaling, treasury/rice, province/ruler ownership, continuation and persistent saves. Visually the NES Classic player sees the same six root commands, submenus, response prompts, notices, 41 authentic tactical maps, unit indicators, terrain interaction and battle outcome. Enhanced may change upstream strategic/economic quantities by approved design but cannot silently modify the default combat engine. The implementation may use Python, C#, arrays, records, pure functions or any sane architecture. Original NES source byte identity, fixed CPU addresses, emulator cycle timing and hardware PRNG bits are not required. Matching original logical probability distributions plus controlled random-stream outcomes IS required. No artificial player advantages or unapproved redesign.
