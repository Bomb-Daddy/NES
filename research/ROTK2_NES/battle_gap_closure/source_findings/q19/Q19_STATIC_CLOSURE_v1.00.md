### Five-way planner `$D15B` / body `$D160`

1. Call `comroot:$A221`, updating the preferred rival from hostility. A rival is set when hostility exceeds `90-5*d`; an existing rival is cleared below `35-5*d`. Setting a rival may break an alliance through `$8522`.
2. If `rand(100)<10*d+20`, set `$FD0B=2` and dispatch overlay 4. `excsub5:$C59D` appoints an advisor (`$C545`) and runs counterspy cleanup (`$C46C`).
3. Let `n` be the number of officers in `P`; set byte action budget to `floor(n/2)+rand(2)`.
4. Set byte starting slot `i=rand(3)` and byte end `end=i+2*d`.
5. While `i<end` and budget is nonzero, choose `i % 5`: 0→`D131`, 1→`D004`, 2→`B97A`, 3→`CF7C`, 4→`B8D1`. Return 1 immediately if the selected routine returns nonzero; otherwise increment `i` and decrement budget. Return 0 when exhausted.

This is a bounded rotating action sequence, not five independent random actions each turn. It preserves actual RNG call order and byte truncation.

## 4. Q19-A: complete planner branches

### A1. `$D131`: pursue a diplomatic partner

Historical symbol: `dispatch_officer_combat_cell`, body `$D136`.

If `R[8]==R[9]`, return 0. Otherwise call `$CD0C($F204+34*R[8], allow_marriage=1)`. There is no explicit `$FF` range guard in this small wrapper; the caller/state invariant must supply a valid preferred partner. Do not manufacture a new sentinel check in Classic.

Shared `$CD0C(partner, allow_marriage)`:

1. If `partner` is already allied with `R`, write `R[8]=$FF` and return 0.
2. Require `$404A(partner)`: the ruler has a province, its first province is governed by its ruler officer, and its province `+F` status is `$FF`. Otherwise return 0.
3. Let `h=partner[E + index(R)]`, its hostility toward the current ruler. If partner index equals `R[9]`, return 0.
4. If marriage is allowed, `h>70`, `R[21]==$FF`, and `R[7]&2` is clear, choose action `$02` and chance `$788F(partner,E)`.
5. Otherwise, if `h>60` and `P.gold>300`, choose action `$03` (gift). Choose `gift=min(1000, rand(P.gold-200)+100)`, subtract it from `P.gold`, set `$FD8C=gift`, `$FD92=0`, and preselect success (`$FD9D=0`).
6. Otherwise choose action `$00` (alliance) and chance `$7981(partner,E)`. For the non-gift cases, set `$FD9D=0` if `rand(100)<chance`, else 1.
7. Set actor `+2` bit `$01` via `$8103`, `$FD8A=E`, and `D=word[partner+2]`; invoke common `$B522`.
8. For gifts, refund the source gold if `$FDA0` is 2 or 3, or if `$FDA0<2` and final `$FD9D` is 1 or 3. The final status is used, not merely the initial probability roll.
9. Return 1 if `$8366` says current-ruler termination flag `R[7]&1` is set or `owner(P)==0`; otherwise return native `$BBA3` (advance actor queue).

### A2. `$D004`: prepare joint action against an existing target

Historical symbol: `scan_officer_province_links`, body `$D009`.

1. `$8389` validates an existing joint agreement: if `R[1E]!=$FF` but owner of province `R[1F]` no longer matches ruler index `R[20]`, clear `R[1E]=$FF` and `R[7]&=$F7`. If an agreement remains, return 0.
2. Walk `R`'s province chain in order. Skip provinces whose `+F!=$FF`. For each planned target `province[13]!=$FF`, resolve the target. If it is unowned or belongs to the same ruler as `P`, clear that province's target field and continue. Stop at the first remaining hostile-owned target. If none, or if target `+F!=$FF`, return 0.
3. `$A191(target)` searches the target's neighbors in adjacency order. Candidate must pass `$82D8` (eligible foreign-owned province) and belong to a different ruler from the target. Prefer the first allied candidate owner. Otherwise take the first with hostility toward us below `90-10*d`; double that hostility, as a byte, if candidate ruler index equals `R[9]`.
4. If no partner is found, or `rand(100)<30`, return `$CE55(target)` (covert action).
5. If partner fails `$404A`, return **1**. Otherwise call `$CD0C(partner,0)`; if that returns nonzero, return 1. If partner still is not allied, return 0.
6. Record target in `$FC28` and `$FD90`, mark actor acted, set action `$01`, messenger `$FD8A=E`, and diplomatic destination to partner's first province. Roll against `$794A(partner,E)`, run `$B522`, then return `$8366 ? 1 : $BBA3`.

The source distinguishes selecting a hostile strategic target from actually initiating its battle. This function can form an alliance, record a future joint agreement, perform a scheme, or do nothing.

### A3. `$B97A`: recruit a foreign officer

Historical symbol: `rank_officers_B97A`, body `$B97F`.

Target selection `$A0BB` builds a list of other rulers through `$6A2D(0)`. If empty, return 0. Make at most `d` attempts, selecting a random ruler each time (selection can repeat), walking that ruler's valid provinces in chain order and using `$A0A1→$9FDE` to find the first vulnerable officer. No target returns 0.

Recruitment mode, in order:

| Mode | Selection gate | Cost/result input |
|---:|---|---|
| 0 | Actor is ruler and `rand(100)<E.war` | Personal recruitment; no gold/horse charge |
| 1 | `P[17]!=0` and `rand(100)<T.war` | Horse; one horse charged after applicable completion |
| 2 | `P.gold>500` and `rand(100)<10` | Set `$FD8C=100`, `$FD92=0`; 100 gold charged after applicable completion |
| 3 | All remaining cases | General recruitment appeal; no gold/horse charge |

The mode labels are corroborated by `excsub1` dispatch table `$CA59`: `$CA61`, `$CA81`, `$CAAC`, `$CAD0`, including the horse and 100-gold messages.

Compute chance through `$7AB5(T,E,mode)` and roll `rand(100)<chance`. If `R` has an advisor, the roll failed, and a further `rand(100)<80`, return 0 **without** marking the actor or conducting the attempt. Otherwise mark actor acted, set action `$0A`, messenger `$FD8A=E`, mode `$FDA8`, pre-result `$FD9D`, save old target ruler, and call `$B522`.

If `$FDA0==3`, skip further cost/message handling. If `$FDA0!=2`, deduct mode 1 horse or mode 2 gold even after an ordinary failed attempt. The success announcement requires `$FDA0<2` and final `$FD9D==0`. Finish via `$8366 ? 1 : $BBA3`.

The successful action reaches `$AD99→$87DD`:

- Ordinary officer/advisor: unlink from old province, insert into current province, set acted, change liege, recompute loyalty and clear applicable covert state. Clear the old ruler's advisor pointer if this was the advisor.
- Governor: each subordinate either follows through the normal recruitment chance or retreats to an eligible neighboring province of the old ruler (`$877A`); without such refuge it is detached and processed through `$4EB0`, which zeroes troops, restores training to 100, returns a spy to its recorded original ruler if possible (`$4E2D`), and otherwise clears covert bits and appends it to the unaffiliated list (`$5122`). The province is removed from the former ruler chain, inserted into the new ruler chain, and ownership changes. Province policy bit `$04` and planned-target bytes `+12/+13` are cleared; the current province's target is also cleared when it pointed here. This is diplomatic province acquisition, not a battle launch.
- The common terminal also handles unaffiliated officers, although `$A0BB` does not ordinarily select that category. Preserve the common terminal's spy-owner and allegiance rules instead of replacing it with an unconditional list move.

### A4. `$CF7C`: choose a rival frontier for covert action

Historical symbol: `draw_combat_anim_cell`, body `$CF81`.

If `R[9]==$FF`, return 0. Otherwise walk that rival ruler's province list. Skip `+F!=$FF`; build adjacency for each remaining province. The first rival province with an owned adjacent province belonging to the same ruler as `P` is passed to `$CE55`; return its result. If no such province exists, return 0. There is no tactical cell draw or ranking operation in this decision.

Shared `$CE55(target_province)`:

1. Set `D=target_province`, resolve owner. Select a vulnerable target officer via `$A065` for `+F!=$FF`, otherwise `$A0A1`. No officer returns 0.
2. For a normal province only, `rand(100)<20` chooses spy planting: set `$FD0B=3`, dispatch overlay 4 (`excsub5:$C355`), and return native `$BBF6`.
3. If target owner is allied and `rand(100)<50`, return 0.
4. Otherwise `rand(100)<50` chooses action `$09` (future defection promise), chance `$7796`.
5. Otherwise, if this is a battle-status province or the target governor is a ruler, choose action `$0B` (forged-letter scheme), chance `$7734`.
6. Otherwise choose action `$07` (incite independence), replace `T` with the target governor and use chance `$77F9`.
7. Roll success; mark actor acted, set `$FD8A=E` and `$FD9D`; call `$B522`; finish via `$8366 ? 1 : $BBA3`.

Shared vulnerability selector `$9FDE` skips a ruler, a target sharing the protected mask with its ruler, a target for which `rand(100)<loyalty`, or any already marked spy (`+2 &2`). Accept when `loyalty < compat_distance(target,ruler)+80`. Otherwise only a governor gets the extra `rand(100)<100-loyalty` gate. Walk to the next officer when rejected.

**Source quirk:** `$9FE3–9FE7` initializes the walk from `word[D+2]` and overwrites the incoming second argument at `$A05D–A05E`. Thus `$A065` copies its battle record and supplies an argument, but the common selector still starts at the target province's linked officer head. Do not assume the argument is the scan start merely from the C signature.

### A5. `$B8D1`: activate a planted spy

Historical symbol: `rank_officers_B8D1`, body `$B8D6`.

Scan all 41 provinces from `$F424`. Skip `+F!=$FF`. In each, `$B891` walks the officer list for `officer[2]&2`, `officer[A]==index(R)`, and `(officer[2]&4)==0`. Stop at the first candidate; if the final target pointer is zero, return 0.

On success `$AD99` sets target `+2` bit `$04`, after the disclosure helper. The `excsub1:$C35E` text identifies the agreement to switch sides on invasion. On failure the common terminal changes diplomatic hostility/trust and sets target `+A=$FF`.

Unlike A1/A2/A3/A4's non-planting branches, this wrapper does **not** explicitly call `$8103` to mark `E` acted. Also, it does not initialize `$FD0C` before scanning: if every province is skipped for `+F!=$FF`, an old nonzero target can survive. Those are inspected source properties, not proposals to repair the original.

## 5. Terminal state changes and numerical contracts

### Common result route

`$B522` computes a route, initializes `$FDA0=0`, and walks it, calling interception test `$B2FB`. It stops travel for `$FDA0>=2` and returns immediately for `$FDA0>=5`. It calls destination executor `$AF51` only for `$FDA0<=1`. `$AF51` sets destination/owner fields and calls `$AD99` for actions `$07–$0C`; ordinary diplomacy goes through response selection and handler table to `$AC55` (accepted), `$AC0A` (refused), or `$ABA4` (capture disposition).

Thus an initial success roll is not a guarantee that the terminal effect occurs. Interception, human response, capture and other common outcomes can replace it. The wrappers' final-cost/refund conditions above intentionally inspect final flags. `$B522`'s return value itself is not used as the action success flag.

| Action | Successful state changes | Relevant terminal |
|---:|---|---|
| `$00` alliance | Set both ruler alliance-mask bits at `+A`; reduce hostility in both directions by 20 with saturation; clear rival and planned targets against each other | `$AC55→$8718→$862A` |
| `$01` joint action | `R[1E]=partner index`, `R[7]&=$F7`, `R[1F]=target province index`, `R[20]=current target owner index` | `$AC55→$86CF` |
| `$02` marriage | `R[21]=partner index`; multiply mutual hostility by 10/100; clear rival/targets against partner | `$AC55→$866B` |
| `$03` gold gift | Credit target ruler's first province, cap 30,000; subtract `floor(gift*(E.charm+50)/10000)+rand(3)` from hostility in both directions with saturation | `$AC55→$85E0→$85CC` |
| `$07` independence scheme | Saturating loyalty loss `rand(16)+5`; set target `+2` bit `$08` | `$AD99:$AE69` |

### Probability helpers: preserve widths and opaque selectors

These are exact source contracts, not newly estimated probability models. Intermediate probability locals in these helpers are **bytes**; wrap on assignment and saturating subtraction through root `$6795` matter. The final test compares `rand(100)` to that byte; there is no universal final clamp to 100.

- `$7717(R)`: advisor intelligence when advisor exists, otherwise `floor(ruler.intelligence*80/100)`.

Compute the native widened multiply/divide `floor(q*(R[6]+b)/((d+3)*50))`, store as byte, then if E is ruler scale by 110/100 and store as byte. Do not substitute names for `base(T,0/2)` from unrelated NES tables without checking identity.
- `$77F9(partner,T,E)`: return zero if ruler-count byte `$E009>=16` or T is marked spy. Otherwise byte accumulator `floor(E.charm/5)+base(T,2)+100`, followed by saturating subtraction of `5*d+T.loyalty+base(T,0)`.

`R[6]` is retained as the source ruler field here. The numerical contract is independent of a UI label. The native `$688A` helper uses a widened multiply/divide path; it must not be conflated with VM opcode `$B5`'s low-word multiply used in transfer rice.

### Spy planting and advisor/counterspy terminal overlay

`excsub5:$C355` requires at least six officers in source P. It starts after the governor, seeks loyalty 100, `max(intelligence,war,charm)<80` (`$606F`), eligibility `$3FD9`, and no protected-mask intersection with our ruler. It rejects planting when existing own spies in the target officer list exceed `floor(target officer count/4)`.

The selected officer is unlinked; independence flag `+2&8` and covert bits `+3&$70` are cleared; advisor pointer is cleared if needed. A previously marked spy follows `$4EB0`'s cleanup route. Otherwise `$C30D` processes troop state, old liege and `+9` are saved in `+A/+B`, liege becomes `$FF`, and `$5122` appends the officer to the target's unaffiliated list (also sets troops zero and training 100); spy bit `$02` is set.

`$C30D` has a literal write quirk: while walking the source officer list, the increment goes to the selected officer's troop word, not the walked officer's word. Preserve exact writes when implementing Classic; do not call this proven redistribution to other officers. Its caller then clears the spy's troops through `$5122`.

The occasional `$C59D` path first appoints the highest-intelligence nonruler officer with intelligence at least 80 from current province onward in the linked chain (`$C545`). Counterspy `$C46C` skips governors and invalid provinces. An exposed spy (`+2&$20`) has a 100 threshold; other spies use `2*max(0,our_advisor_score-floor((advisor_score(ruler(spy))+spy.intelligence)/2))+rand(5)`, stored as byte. Nonspy covert flags `+3&$70` use `floor(our_advisor_score/3)`. A successful cleanup of a spy unlinks it and invokes `$4EB0`; after any such removal it restarts the actor queue with `$BBF6`.

## 6. Q19-B: `$D409` transfer, with exact gates

### Entry and candidate list

1. `$9EAB` gets `v=base(L,2)`. If `v<60`, replace it with `floor(v/3)+2`. Continue only if `rand(100)<v`.
2. `$9F11(P)` ORs adjacency flags: 1 for any unowned neighbor, 2 for any neighbor not owned by our ruler. It does not restrict the latter to nonallied rivals. Same-owner neighbors add nothing.
3. Native `$6A8F(P,flags)` builds pointers at `$FA43`. Flags are 1 only when the governor is the ruler and the adjacency status is zero; otherwise 9. Mask `$01` includes the employed-officer list; mask `$08` skips its first/governor entry. **It does not apply the queue's acted/status eligibility filter.** Order is linked-list order.
4. Require candidate count `n >= (is_ruler(governor) ? 7 : 2) + (adjacency_status!=0 ? 3 : 0)`.
5. Let `total=$694F(P)` (word total troops). Require `floor(P.rice/2)>=total`.
6. `rand(100)<70` selects `$D394`; otherwise `$D220`. Require a nonzero destination and `destination officer count < n`.

### Destination proof

| Selector | Admitted destination | Hostile-occupied rejection |
|---|---|---|
| `$D394` direct neighbor | First unowned neighbor, or same-owner valid neighbor whose governor is ruler and officer count is below 5 | Owner equality at `$D3B8–$D3CF`; unequal goes to next neighbor |

## 7. Native terminal `$BBA3/$BBF6`: exact return meaning

These addresses contain native 65C816, not KOEI VM bytecode. The recovered region is `comroot:7E:BBA3–BC77`. `$BC20` loads province head H, points `$0E` to current actor `$FD9E` and `$10` to next actor `$FDFA`.

`$BC37` returns eligible iff `(officer[2]&1)==0 && (officer[3]&15)==0`. `$BC54` follows next pointers until that eligibility predicate holds or the chain ends.

`$BBA3`:

1. Copy next actor `$FDFA` into current actor `$FD9E`.
2. If zero, return 1.
3. Scan from that actor's successor for the next eligible officer, and write it to `$FDFA`.
4. If no successor was found, actor is not H, and H is eligible, write H to `$FDFA` as a final wrap.
5. Return 0 whenever a current actor was selected, even if no further next actor remains.

`$BBF6` resets the starting position: if H has a successor, scan from that successor for an eligible officer; otherwise set next actor to H. Then enter `$BBA3`'s body. Two exact edge behaviors follow:

- A lone governor is selected even if its acted bit is set; the restart path does not eligibility-check the head in this branch.
- If subordinate entries exist but all are ineligible, restart returns 1 with actor zero, even if H itself is eligible. It does not fall back to H before entering `$BBA3`.

These are reproduced by original-native-byte synthetic fixtures. `$BBF6` has no destination argument, no ownership-attack test, no battle-state initialization and no combat overlay load.
