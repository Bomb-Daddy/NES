# Build40R3 no-music edition (source candidate, NOT final release)
This is the complete original Build40R3 source plus three narrowly
adjusted optional-music checks; all 15 arranged private MP3 tracks
are separated into the optional Music Assets.zip archive.
All generated WAV sound effects remain in the game package.

The game starts and operates without the music archive. When music is
absent, Audio Status reports that the private soundtrack is missing.
For private use with rights to those tracks, overlay the optional
Music Assets.zip into the project root and relaunch. See MUSIC_ASSETS_README.txt.

Public GitHub publication of the MP3s is NOT authorized by their source
license (distribution permission has not been verified). No live game
mechanics, gameplay data, or launcher routing were intentionally changed.
This is a candidate: full Director game acceptance remains outstanding.
